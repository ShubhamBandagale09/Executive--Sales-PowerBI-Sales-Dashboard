📊 Executive Sales Dashboard | Power BI Project
📌 Project Overview

This project showcases an interactive Executive Sales Dashboard built using Microsoft Power BI to analyze business performance across countries, product categories, sales channels, and months.

The dashboard provides valuable insights into revenue, gross profit, gross margin, orders, and units sold, helping business stakeholders monitor performance and make data-driven decisions.

🖥️ Dashboard Preview

🎯 Project Objectives
Analyze overall sales and profitability.
Track monthly revenue and gross profit trends.
Identify top-performing and lowest-performing countries.
Compare product categories based on units sold.
Analyze revenue generated by different sales channels.
Evaluate gross margin across geographical regions.
Identify the months with the highest number of orders.

🎛️ Interactive Filters

The dashboard includes three interactive slicers:

Country: Filter sales performance by country.
Month Name: Analyze performance for specific months.
Product Category: Explore sales across different product categories.
